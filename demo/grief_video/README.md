# TACO Grief Demo Video

A reproducible ~66-second Remotion artifact for the TACO grief retrieval proof.

## Design

- Apple-keynote style: quiet, white, minimal, high-trust.
- Inter for UI copy and JetBrains Mono for state / scoring traces.
- Monochrome palette with restrained gray contrast.
- Designed to work with or without voiceover; captions are always visible.
- Low-volume generated ambient bed under the narration.

## Data

The video reads `public/data/grief-trace.json`, generated by:

```bash
python3 -m eval.grief_demo_trace --out demo/grief_video/public/data/grief-trace.json
```

## Voiceover

Voiceover is optional and cached. Add these to the repo-root `.env` or this
folder's `.env`:

```bash
ELEVENLABS_API_KEY=...
ELEVENLABS_VOICE_ID=... # required for free-tier API generation
ELEVENLABS_SPEED=0.82 # optional; lower is slower
```

Then run:

```bash
npm run voiceover
```

If the key or voice ID is missing, invalid, or not available on your plan, the
video still renders captions-only.

## Preview And Render

```bash
npm install
npm run sfx
npm run music
npm run dev
npm run still:all
npm run render
```

The rendered MP4 is written to `out/taco-grief-demo.mp4` and is intentionally
ignored by Git.
